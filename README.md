# 🌊 Ozean | أوزيان: إبداعك، عالمك

منصة لبيع وشراء الأعمال الإبداعية، تجمع الفنانين والمبدعين وعشّاق الفن في مكان واحد.

🌐 **الموقع:** https://tecnexus555.github.io/ozean.com/

## 🚧 حالة المشروع

المنصة حاليًا في **مرحلة العرض التجريبي**: يمكنك تصفّح الواجهة والأقسام والمزادات ببيانات تجريبية.
**تسجيل الدخول ونشر الأعمال وحفظ الطلبات سيتفعّل قريبًا** بعد ربط المنصة بقاعدة بياناتها (Firebase). سنعلن ذلك هنا عند الجاهزية.

---

## 🎯 رؤيتنا

أن يجد كل مبدع مساحة تعرض فيها أعماله وتصل إلى من يقدّرها، وأن يجد كل محبّ للفن أعمالًا أصلية يثق بها.

## ✨ ماذا تقدّم المنصة؟

- **متجر متنوع:** لوحات، صور، موسيقى، فيديو، أزياء، أحذية، مجوهرات، منتجات يدوية، وتصاميم رقمية.
- **مزادات مباشرة:** اعرض عملك للمزايدة بسعر بداية وأقل زيادة ووقت انتهاء تحدده أنت.
- **حماية الأعمال:** علامة مائية تلقائية على الصور، وتوثيق العمل بشهادة ملكية رقمية.
- **التحقق من الملكية:** ارفع ملفًا لتعرف إن كان مطابقًا لعمل موثّق في المنصة.
- **صفحة عامة للفنان:** اعرض أعمالك وشاركها مباشرة على منصات التواصل.
- **خمس لغات:** العربية، English، Türkçe، Español، Italiano.

## 🎨 هل أنت فنان أو مبدع؟

*(يتفعّل قريبًا مع ربط قاعدة البيانات)* بعد تسجيل الدخول بحساب Google، ستجد في **لوحة الفنان**:

1. ارفع عملك (حتى 4 صور للعمل الواحد) وأضف الوصف.
2. حدّد التسعير: سعر ثابت، أو مجاني، أو بالتفاوض، أو مزاد.
3. تابع طلبات العملاء وأكّد الطلب بعد استلام الدفع.
4. شارك صفحتك وأعمالك مع جمهورك.

## 🛍️ هل تبحث عن عمل فني؟

تصفّح الأقسام والمزادات الآن. وعند تفعيل الحسابات ستنشئ طلبك، وبعد تأكيد الفنان للدفع تنزّل العمل الأصلي من حسابك.

## 💳 الدفع

الدفع حاليًا **بالتحويل المباشر** بين المشتري والفنان (محفظة أو مصرف داخل ليبيا، أو تحويل دولي لمن هم خارجها)، ثم يرسل المشتري الإيصال ويؤكده الفنان. لا يوجد خصم تلقائي من أي حساب.

## 🛠️ التقنية

HTML وCSS وJavaScript، مع Firebase للدخول وقاعدة البيانات والتخزين. لتشغيل نسختك الخاصة اقرأ [دليل التشغيل](SETUP.md).
